# Help Reference

## 触发条件

- 用户说：`/amz -help` / `/help` / `help` / `帮助` / `怎么用` / `使用说明` / `功能`
- 飞书卡片回调 `show_help`
- 用户首次完成配置后（欢迎卡片已包含「查看帮助」按钮）

## 执行流程

使用飞书插件「发送消息」发送灰色主题的帮助卡片，列出所有可用能力。
内容要简洁可扫读，不要大段文字。

## 帮助卡片结构

```
📘 Amazon 监控 · 使用指引
─────────────────────────
🔍 查询
  ·「{ASIN 或商品名} 最近怎样」      — 单品趋势
  ·「现在所有商品怎么样」            — 全量状态
  ·「{类目} 的爆款榜单」             — Amazon Top 榜
                                    类目：电子/书籍/玩具/厨房/
                                    服装/运动/美妆/家居

📦 商品管理
  ·「帮我监控 B0XXXXXXXX」           — 添加
  ·「删除 B0XXXXXXXX」 / 「删除 {备注}」— 移除
  ·「列表」 / 「监控哪些商品」       — 查看全部
  ·「给 B0XXXXXXXX 加备注 竞品A」    — 修改备注

📈 报告
  ·「生成周报」                      — 过去 7 天汇总
  ·「生成月报」                      — 过去 30 天汇总

⚙️ 运维
  · /amz 「刷新」 / 「立即检查」     — 手动触发一次监控
  · /amz 「重新配置」                — 修改市场 / Key / 飞书 Token
  · /amz -help                       — 显示本帮助

─────────────────────────
⏱ 自动监控周期：每 {interval_minutes} 分钟一次
📊 排名异动阈值：{alert_threshold} 位（超过即告警）
📁 数据存储：飞书多维表格（[查看]）
─────────────────────────
[查看文档]   [管理商品]   [重新配置]
```

- `[查看文档]` → URL 跳转 `https://xxx.feishu.cn/docx/{feishu_doc_token}`
- `[管理商品]` → callback action: `manage_products`
- `[重新配置]` → callback action: `reset_config`（走 setup.md 流程）
- `[查看]`（数据存储旁） → URL 跳转 `https://xxx.feishu.cn/base/{feishu_bitable_token}`

## 分层帮助（用户问具体子主题时）

若用户进一步问「怎么加商品」「报告是什么样的」等具体子问题，按下表定向回复，不要重复展示全量帮助卡片：

| 子问题 | 直接指向 |
|--------|---------|
| 怎么添加 / 删除商品 | 回复 2-3 句示例 + `[管理商品]` 按钮 |
| 报告长什么样 / 里面有什么 | 描述报告结构，提供「生成周报」快捷按钮 |
| 告警怎么触发 | 说明 `abs(rank_delta) > 3` 规则 |
| Rainforest / 爬取区别 | Rainforest 稳定但需 Key；无 Key 自动降级爬取 |
| 数据存在哪里 | 飞书多维表格，提供表格 URL |

## 未配置时的帮助

若用户在未完成初始配置时请求帮助：
- 优先引导走配置流程：「你还没完成初始配置，先来设置一下吧」
- 然后加载 `setup.md`
