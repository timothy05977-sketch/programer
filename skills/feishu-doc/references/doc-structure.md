# Feishu Document & Bitable Structure

## 飞书文档结构

文档采用追加模式，每 20 分钟在末尾新增一个区块，结构如下：

```
[H1] 📈 Amazon 商品监控追踪                ← 文档固定标题（首次创建时写入）

[H2] 📊 2026-04-18 14:20 监控快照         ← 每轮追加，时间戳为区块标题

[表格] 全量商品数据
| ASIN | 商品名 | 当前排名 | 排名变化 | 价格 | 趋势标签 |

[段落] 焦点商品摘要
本轮焦点：{title}（{asin}），排名 {delta描述}。{summary}

[图表] 排名趋势（由 Bitable 数据驱动，需在飞书文档中手动关联）

─────────────────────────────────             ← 分隔线

[H2] 📊 2026-04-18 14:00 监控快照
...
```

使用飞书插件「更新云文档」工具时，每次追加上述结构（从 H2 到分隔线）。

## 多维表格（Bitable）字段规范

Bitable 用于驱动文档内嵌图表，每次刷新每个监控商品写入一条记录。

### 数据表字段

| 字段名 | 字段类型 | 说明 | 示例值 |
|-------|---------|------|--------|
| ASIN | 文本 | 商品 ASIN | B0CHWX8DFH |
| 商品名 | 文本 | 截断至 50 字 | 蓝牙耳机 XXX |
| 记录时间 | 日期时间 | UTC+8，格式 YYYY-MM-DD HH:mm | 2026-04-18 14:20 |
| 当前排名 | 数字 | sales_rank，无数据填 0 | 18 |
| 排名变化 | 数字 | 正数=提升，负数=下降 | 24 |
| 当前价格 | 数字 | price_value，无数据填 0 | 24.99 |
| 趋势标签 | 单选 | 固定选项见下方 | ⚠ 异动 |
| 数据来源 | 单选 | rainforest / scraper | rainforest |

### 趋势标签单选选项

- 📈 上升
- 📉 下降
- ➡ 稳定
- ⚠ 异动
- — 数据不足

### 写入示例（飞书插件调用参数）

```json
{
  "fields": {
    "ASIN": "B0CHWX8DFH",
    "商品名": "蓝牙耳机 XXX",
    "记录时间": 1713441600000,
    "当前排名": 18,
    "排名变化": 24,
    "当前价格": 24.99,
    "趋势标签": "⚠ 异动",
    "数据来源": "rainforest"
  }
}
```

`记录时间` 为毫秒级 Unix 时间戳（UTC+8）。

## 图表配置建议

在飞书文档中手动插入「图表」组件，关联上述 Bitable 数据表：

- **排名趋势图**：折线图，X 轴=记录时间，Y 轴=当前排名（**注意：Y 轴反转**，数值越小排名越高），按 ASIN 分组
- **价格趋势图**：折线图，X 轴=记录时间，Y 轴=当前价格，按 ASIN 分组
